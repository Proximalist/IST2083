🎯 Öğrenme Hedefleri

Bu oturumun sonunda:

  • Bir grafiğin özet istatistiklerin göremediği şeyi neden gösterdiğini açıklayabileceksiniz
  • Bir ggplot2 kodunu katman katman okuyabileceksiniz
  • Eşleme (aes() içi) ile sabit ayarı (aes() dışı) ayırt edeceksiniz
  • Değişken türüne göre doğru grafiği seçeceksiniz
  • Log ölçek, faset ve üçüncü değişkenin etkisini yorumlayacaksınız
  • Bir grafiği başkası için hazırlayıp kaydedeceksiniz

2) Grafiklerin dilbilgisi

2) Asgari şablon

ggplot(data = <VERİ>, mapping = aes(<EŞLEMELER>)) +
  <GEOM_FONKSİYONU>()
  • Veri: her satır neyi temsil ediyor?
  • Eşleme: hangi sütun → hangi görsel özellik?
  • Geom: nokta, çubuk, çizgi, kutu?
  • + satırın sonunda durur

2) Adım adım

ggplot(gapminder_2007, aes(x = gdpPercap, y = lifeExp)) +
  geom_point()

3) Eşleme mi, sabit ayar mı?

ggplot(gapminder_2007, aes(gdpPercap, lifeExp, color = continent)) +
  geom_point()
ggplot(gapminder_2007, aes(gdpPercap, lifeExp)) +
  geom_point(color = "steelblue")

Veriye bağlı → aes() içine. Herkese aynı → aes() dışına.

3) Yaygın hata: sabit değer aes() içinde

ggplot(gapminder_2007, aes(gdpPercap, lifeExp, color = "blue")) +
  geom_point()
  • Noktalar mavi değil, lejantta “blue” yazıyor
  • "blue" burada tek kategorili bir değişken

4) Histogram: bir satır = bir ülke

ggplot(gapminder_2007, aes(x = lifeExp)) +
  geom_histogram(binwidth = 5, fill = "grey70", color = "white") +
  labs(x = "Yaşam beklentisi (yıl)", y = "Ülke sayısı")
  • İki tepe: dünya iki grup gibi davranıyor
  • binwidth bir karardır: çok dar → gürültü, çok geniş → yapı kaybolur

4) Kutu grafiğini okumak

  • Kalın çizgi: ortanca · Kutu: ortadaki yarı
  • Bıyık: 1,5 kutu boyunu aşmayan en uç gözlem
  • Noktalar: bakılması gereken gözlemler (hata değil)
  • Sınırı: iki tepeli yapıyı göstermez

4) geom_bar() mı, geom_col() mı?

Veri Arka planda y
geom_bar() Ham (her satır bir gözlem) stat = "count" — sayar Verilmez
geom_col() Özetlenmiş (hazır sayı/oran) stat = "identity" Verilir 
ggplot(gapminder_2007, aes(x = continent)) + geom_bar()
gapminder_2007 |> count(continent) |>
  ggplot(aes(x = continent, y = n)) + geom_col()

Koalisyon partileri bakanlıkları sandalye payları oranında paylaşır

5) Gamson grafiğinden üç ders

  • Aşırı çizim: 826 nokta üst üste biniyor → alpha veya geom_jitter()
  • Referans çizgisi (geom_abline) grafiği bir iddiaya karşı okutur
  • Sapma: küçük partiler payından fazla, büyük partiler az alıyor → pazarlık gücü

6) Gruplar: yan yana kutu grafikleri

ggplot(gapminder_2007,
       aes(x = reorder(continent, lifeExp, FUN = median), y = lifeExp)) +
  geom_boxplot(outlier.shape = NA, color = "grey40") +
  geom_jitter(width = 0.15, height = 0, alpha = 0.5) +
  labs(x = NULL, y = "Yaşam beklentisi (yıl)")
  • Okyanusya’nın kutusu yalnızca 2 ülke — noktalar bunu gösteriyor

7) Konum ayarları: stack, dodge, fill

  • “Hangi grup kalabalık?” → stack · “Grup içinde oy nasıl dağılıyor?” → fill

7) Alfabe tuzağı

  • R, “Agree”nin “Strongly agree”den önce gelmediğini bilemez
  • Sıralı kategorilerde sırayı siz verirsiniz:
factor(vfproblem,
       levels = c("Strongly disagree", "Disagree", ..., "Strongly agree"),
       labels = c("Kesinlikle katılmıyorum", ..., "Kesinlikle katılıyorum"))
  • Doğal sırası olmayan kategoriler (kıta, parti) → değere göre sırala: reorder()

8) Zaman: group estetiği

ggplot(gapminder, aes(year, lifeExp)) +
  geom_line()
ggplot(gapminder, aes(year, lifeExp, group = country)) +
  geom_line(alpha = 0.2)

  • group hangi noktaların aynı çizgiye ait olduğunu söyler

8) Bir ülkeyi öne çıkarmak

turkiye <- gapminder |> filter(country == "Turkey")

ggplot(gapminder, aes(year, lifeExp, group = country)) +
  geom_line(color = "grey80") +
  geom_line(data = turkiye, color = "firebrick", linewidth = 1.2)

9) Log ölçeği

ggplot(gapminder_2007, aes(gdpPercap, lifeExp)) +
  geom_point(aes(size = pop, color = continent), alpha = 0.6) +
  scale_x_log10() +
  scale_size_area(max_size = 12, guide = "none")
  • Eşit oranlar, eşit aralık · Eğri → doğru

9) Genel ve yerel eşleme

ggplot(g, aes(x, y, color = continent)) +
  geom_point() +
  geom_smooth(method = "lm")

→ Her kıta için bir doğru

ggplot(g, aes(x, y)) +
  geom_point(aes(color = continent)) +
  geom_smooth(method = "lm")

→ Tek bir doğru

  • ggplot() içindeki eşleme bütün katmanlara miras kalır

10) Simpson paradoksu: harcama ve SAT

  • Bütünde negatif, her grubun içinde pozitif
  • Üçüncü değişken (katılım oranı) ikisini birden etkiliyor → 10. oturum

11) Grafiği başkası için hazırlamak

  • title: konu değil bulgu yaz
  • Eksen adı: değişken adı değil, anlam + birim
  • caption: kaynak ve kararlar (çıkarılan gözlemler, log ölçek)
  • Renk: kırmızı–yeşil yok → scale_color_viridis_d()
  • Çubuk grafiği sıfırdan başlar — nokta ve çizgi grafiği başlamak zorunda değil
  • Kaydet: ggsave("grafik.png", plot = p, width = 16, height = 10, units = "cm")

12) Hangi soru, hangi grafik?

Soru Grafik
Değerler nasıl dağılıyor? geom_histogram()
Kategoriler ne sıklıkta? geom_bar() / geom_col()
İki değişken birlikte nasıl değişiyor? geom_point()
Gruplar nasıl farklılaşıyor? geom_boxplot()
Grup içi dağılım? geom_bar(position = "fill")
Zaman içinde? geom_line()
Üçüncü değişken? color veya facet_wrap()
